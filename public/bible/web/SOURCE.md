# Bible text source

The book and chapter data in this directory is derived from the World English Bible Protestant Edition (WEBP), official 66-book edition. The translation text is public domain. Source files: https://ebible.org/Scriptures/engwebp_usfm.zip

The Bible text is preserved; USFM formatting and non-scripture notes are omitted for display. Source information and public-domain statement: https://ebible.org/engwebp/copyright.htm
